# 🧪 开屏广告 UI 形态（单页式 vs 双页式）A/B 测试 PRD

---

## 1. 实验背景与假设

* **业务背景**：当前 App 热启动开屏广告采用传统的“单页式（Single-page Splash）”直接加载展示形态。
* **核心假设**：引入“双页式（Two-stage/Pre-splash Page）”展示形态（即先展示极简的前导页/加载过渡页，再渲染广告），可增加广告 SDK 的预加载缓冲时间，从而**提高开屏广告的填充率（Fill Rate）与高价位 Floor 的展示率（Show Rate）**，在保护首屏用户体验的前提下拉升开屏 eCPM 与 ARPDAU。
